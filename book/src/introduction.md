# Batchalign documentation

Use Batchalign to transcribe recordings, align checked transcripts with audio,
and add language analysis to CHAT files.

If you are new to Batchalign, begin with the [Quick Start](batchalign/user-guide/quick-start.md).
It walks you through opening a command window and processing your first files.

| What you need | Start here |
|---|---|
| A guided first experience | [Tutorials](diataxis/batchalign-tutorials.md) |
| Steps to complete a particular task | [How-to guides](diataxis/batchalign-how-to-guides.md) |
| Exact commands, options, or data contracts | [Reference](diataxis/batchalign-reference.md) |
| An understanding of how processing works | [Explanation](diataxis/batchalign-explanation.md) |

For common clinical and research workflows, the [Batchalign guide](batchalign/introduction.md)
helps you choose the next task. The sidebar also includes supporting CHAT-format,
Chatter, CLAN, and editor material, grouped by the same kinds of help.
