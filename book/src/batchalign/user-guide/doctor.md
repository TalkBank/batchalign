# Check an installation

The current CLI does not register a `doctor` command. To diagnose an installation:

```bash
batchalign version
batchalign --help
batchalign cache path
```

Then run one small input with the command you need. This checks backend loading
and processing as well as command discovery. See [Troubleshooting](troubleshooting.md)
for next steps and the information to include in a bug report.
