# Batchalign documentation

Batchalign helps you turn conversation recordings into CHAT transcripts and add
language analysis to transcripts you have checked.

## Start here

If this is your first time using Batchalign, follow the [Quick Start](user-guide/quick-start.md).
It shows you how to open a command window, check your installation, and process
a transcript. You do not need programming experience.
