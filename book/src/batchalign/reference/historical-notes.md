These records describe earlier implementations, model probes, or proposals.
They are useful for understanding why earlier choices were made, but are not
current command instructions, support guarantees, or measurements of version 0.10.1.
The links identify a fixed repository revision so the evidence does not drift.

For current behavior, use [CLI reference](../user-guide/cli-reference.md),
[Morphosyntax](morphosyntax.md), [Language selection](language-handling.md), and
[Pipeline architecture](../architecture/command-lifecycles.md).
