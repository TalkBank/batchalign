# TextGrid export

TextGrid is Praat's annotation format. The current Batchalign CLI does not expose
a TextGrid export command or the former `batchalign_core` Python export helper.

For CHAT-to-Praat conversion in the wider toolchain, see
[CHAT2PRAAT](../../clan-reference/commands/chat2praat.md). Check that the input
transcript has the timing required by the converter. Batchalign's alignment
workflow is described in [Align a transcript](../user-guide/commands/align.md).
